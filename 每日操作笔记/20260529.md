# 戒除交易成瘾

你的“努力”在奖励错误行为

玩老虎机你不需要努力。但你会为交易付出大量精力：复盘、看新闻、画线、盯盘。心理学上有个概念叫“努力辩护”（Effort Justification）：你为一件事情付出越多努力，你就会在认知上越认为它有价值，越不愿意放弃。

你的内在逻辑： “我花了这么多时间研究这只股票，它不可能是个错误的选择。”

结果： 当股价下跌时，你不是止损，而是“再加一单，摊低成本”，因为你无法接受自己“付出努力后还犯错”这个事实。你的智商和努力，反而成了你加仓送死的燃料。


1. 正视成瘾本质，先承认：你不是心态差，而是陷入了行为成瘾。不再过度自责内耗，而是像对待问题一样，主动戒断。

2. 强制降低盯盘频率盯盘=持续刺激多巴胺分泌。想戒毒，第一步就是少看、少动、少操作。真正的价值投资者，大部分时间都在研究逻辑，而非盯盘。（这也是巴菲特长期选择住在偏远郊区，而不是闹市华尔街的核心原因——主动远离市场噪音，才能守住理性与耐心。）

3. 把交易计划“写死”，绝不盘中修改计划之外的任何操作，一律视为违规。违规一次，强制停手休息。用刚性规则，对抗情绪冲动，对抗多巴胺诱惑。

4. 只做“逻辑交易”，拒绝“感觉交易”买入，因为逻辑成立；持有，因为逻辑未变；卖出，因为逻辑破坏。不为“怕跌”而割肉，不为“想赚”而追高，不为“手痒”而开仓。

5. 投资的终极修行：修心。修心不是玄学，而是三句话：降低对短期快感的渴望，提升对波动回撤的耐受，守住对交易纪律的敬畏。

当你不再需要从短线波动里寻找刺激，你才有可能真正拿住一只优质标的；当你不再被多巴胺绑架，你才真正迈入成熟投资者的门槛
